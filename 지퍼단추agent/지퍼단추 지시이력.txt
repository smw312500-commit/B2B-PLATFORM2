[2026-06-11 16:00] 플랫폼agent 연결 표준 규격 확정
지시: 지퍼단추agent가 플랫폼agent와 연동할 때 사용할 표준 연결 규격을 라벨agent에서 확정한 방식 기준으로
  이 지시이력에 명시해 둘 것. 이후 지퍼단추사 플랫폼 보고 구현은 이 규격을 기본값으로 따른다.

표준 원칙:
  - 플랫폼에는 회사 DB raw 전체를 보내지 않는다.
  - 지퍼단추agent AI/규칙 엔진이 정리한 판단 결과와 물류/생산 연결에 필요한 핵심 필드만 JSON으로 보고한다.
  - 보고 채널 UI는 자유채팅이 아니라 API 보고 이벤트 타임라인이다.
  - API 호출은 화면이 켜져 있다는 이유만으로 반복 호출하면 안 된다.
    · 발주 생성
    · 입고 확정
    · 생산 상태 변경
    · 돌발상황 발생
    · 출고완료
    같은 "상태 변화 시점"에만 전송한다.
  - 플랫폼 장애가 지퍼단추 업무를 막으면 안 된다.
    · 실패 시 업무는 계속 진행
    · 내부 상태는 "플랫폼 보고 대기"로 남김
    · 동일 report_id로 재시도 가능해야 함

공통 식별/재시도 표준:
  - 모든 플랫폼 보고 payload에는 report_id를 넣는다.
  - report_id는 같은 업무 이벤트의 재시도 동안 절대 바꾸지 않는다.
  - 플랫폼은 source_report_id/report_id 기준으로 dedupe 가능해야 한다.

플랫폼 보고 API 표준:
  - 생산/일정 보고: POST /api/agent-report/schedule
    · 포함값: company_id 또는 company_name, report_type, item/material, qty, due_date 또는
      estimated_completion, status, reason(optional)
  - 재조정/돌발 보고: POST /api/agent-report/reschedule
    · 포함값: report_id, item/material, status, reason, new_estimated_completion(optional)
  - 수입/원자재 입고(BL): POST /api/agent-report/import
    · 포함값: material 또는 item_name, qty, unit, weight_kg, bl_number(optional),
      port_of_loading, port_of_discharge(or receiving_port), supplier/supplier_company,
      receiving_company, receiving_company_location, arrival_date, due_date, note
  - 출고완료/수출: POST /api/collected-release
    · 포함값: item_name, quantity(or release_qty), unit, due_date, release_date,
      status="출고완료", pickup_company, pickup_location, export_port,
      shipment_total_weight_kg(or product_weight_kg), shipment_box_count_total(optional)
    · 라벨 연동건이면 label_code를 반드시 포함
    · 지퍼/단추사 자체 품목 추적값은 related_code/item_ref 성격으로 같이 유지

패킹리스트 표준:
  - 출고완료 묶음에 패킹리스트를 붙일 때는 PDF가 아니라 CSV 기준으로 플랫폼에 전송한다.
  - 필수 포함값:
    · filename (*.csv)
    · content_type = "text/csv"
    · period_from / period_to
    · total_qty
    · total_weight_kg
    · label_code_count 또는 동등한 품목 수량 필드
    · csv_base64
    · csv_size_bytes
  - 플랫폼은 이를 저장하고 download_url로 다시 내려줄 수 있어야 한다.
  - 사용자 다운로드 UI는 CSV/XLSX로 확장 가능하지만,
