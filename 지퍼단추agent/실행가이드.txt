========================================
지퍼단추agent 실행 가이드
========================================

========================================
1. 사전 준비
========================================

  - Python 3.11+
  - Node.js 18+
  - MySQL 서버 실행 중
  - company_zipper 스키마 생성:
      CREATE DATABASE company_zipper CHARACTER SET utf8mb4;

========================================
2. 백엔드 실행
========================================

  cd 지퍼단추agent\backend

  # 환경변수 설정
  copy .env.example .env
  # .env 파일을 열어 DB 접속정보 / OPENAI_API_KEY 입력

  # 패키지 설치
  pip install -r requirements.txt

  # 서버 실행 (포트 8002)
  python main.py

  # 또는
  uvicorn main:app --reload --port 8002

  API 문서: http://localhost:8002/docs

========================================
3. 프론트엔드 실행
========================================

  cd 지퍼단추agent\frontend

  npm install
  npm start

  # 브라우저: http://localhost:3000

========================================
4. DB 테이블 자동 생성
========================================

  백엔드 최초 실행 시 SQLAlchemy가 자동으로
  아래 테이블을 생성합니다:
    - zipper_stock        (완제품 재고)
    - raw_material_stock  (원자재 재고)
    - zipper_order        (발주)
    - zipper_release      (출고)

  초기 데이터도 자동 삽입됩니다.

========================================
5. 포트 정리
========================================

  Backend:  8002
  Frontend: 3000
  MySQL:    3306 (기본값)

  라벨agent Backend:  8001 (다른 에이전트와 충돌 주의)
  옷감agent Backend:  8003 (예정)

========================================
6. OPENAI_API_KEY 없이 실행
========================================

  .env에 OPENAI_API_KEY가 없어도 동작합니다.
  AI 분석 기능은 규칙 기반으로만 실행되며
  GPT 코멘트는 표시되지 않습니다.
