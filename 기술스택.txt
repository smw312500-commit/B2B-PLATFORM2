========================================
기술 스택 확정
========================================
작성일: 2026-05-21

이 파일을 읽는 AI에게:
모든 세션은 아래 기술스택을 반드시 따를 것.
임의로 다른 프레임워크 사용 금지.

========================================
확정 스택
========================================

  프론트엔드: React
  백엔드:     Python FastAPI
  데이터베이스: MySQL (회사별 개별 스키마)
  AI API:     GPT API (OpenAI)

========================================
DB 구성
========================================

  MySQL 서버 1개, 스키마 5개:
    company_fabric      (옷감사)
    company_label       (케어라벨사)
    company_zipper      (지퍼단추사)
    company_logistics   (물류사)
    platform            (중앙 플랫폼)

  상세 스키마: DB세션/DB_설계.txt 참고

========================================
프로젝트 폴더 구조 (예시)
========================================

  각 회사 시스템 구조:
  ├── frontend/         React 앱
  │   ├── src/
  │   │   ├── components/
  │   │   └── pages/
  │   └── package.json
  └── backend/          FastAPI 앱
      ├── main.py
      ├── routers/
      ├── models/
      └── requirements.txt

========================================
FastAPI 기본 설정
========================================

  Python 3.11+
  주요 패키지:
    fastapi
    uvicorn
    sqlalchemy      (MySQL ORM)
    pymysql         (MySQL 드라이버)
    openai          (GPT API)
    python-dotenv   (환경변수)
    pydantic        (데이터 검증)

========================================
React 기본 설정
========================================

  Node.js 18+
  주요 패키지:
    react
    react-router-dom  (페이지 라우팅)
    axios             (API 통신)
    tailwindcss       (스타일링)

========================================
API 통신 방식
========================================

  React → FastAPI: REST API (JSON)
  FastAPI → MySQL: SQLAlchemy ORM
  FastAPI → GPT API: openai 패키지
  FastAPI → 플랫폼: REST API (출고완료 신호 전송)
