## 전체 레이아웃 (스케치1 기준)

```
┌────────────────────────────────────────────────────────┐
│  [회사명] AI Agent              날짜/시간              │
├────────────────────────────────────────────────────────┤
│  [ 재고 ]  [ 발주하기 ]  [ 발주취소 ]  [ 기타 ]       │
├─────────────────────────────────┬──────────────────────┤
│                                 │                      │
│                                 │    AI Agent          │
│        메인 콘텐츠 영역          │    패널              │
│     (탭 클릭 시 내용 전환)       │    (고정)            │
│                                 │                      │
└─────────────────────────────────┴──────────────────────┘
```

- 메인 영역: 좌측 70%
- AI Agent 패널: 우측 30% 고정 (탭 전환해도 항상 표시)

## 탭 목록 (4개 고정)

| 순서 | 탭명 | 설명 |
|------|------|------|
| 1 | 재고 | 현재 재고 현황 조회 |
| 2 | 발주하기 | 신규 발주 등록 및 발주 현황 |
| 3 | 발주취소 | 진행 중인 발주 취소 |
| 4 | 기타 | 설정, 생산속도 로직 등 |

---

## 탭별 테이블 컬럼 (스케치2 기준)

### [ 재고 ] 탭
```
컬럼: 날짜 | 품목명 | 수량 | 단가 | 단위 | 금액 | 기타(날짜/이유/비고 등)
```
- 기타 컬럼: 날짜, 이유, 비고 등 유연하게 활용
- 하단에 AI알림/지시사항/주의사항 영역 표시

### [ 발주하기 ] 탭
```
컬럼: 발주처(발주사) | 날짜 | 기간 | 수량 | 비고
```
- 발주현황과 발주취소 구분 표시
- 신규 발주 등록 폼 포함

### [ 발주취소 ] 탭
```
컬럼: 발주처 | 날짜 | 기간 | 수량 | 비고 | 취소버튼
```
- 취소 가능한 발주만 표시

### [ 기타 ] 탭
```
내용: 생산속도 설정값 (추후 확정 예정)
```
- 현재는 UI만 준비, 로직은 추후 입력

## AI Agent 패널 (우측 고정 영역)

```
┌──────────────────────┐
│  AI Agent            │
│──────────────────────│
│ 납기 현황            │
│  라벨코드  D-?일     │
│  필요시간  ?h        │
│  ✅ 가능 / ⚠ 위험   │
│──────────────────────│
│ AI 지시사항          │
│  우선 생산 품목      │
│  발주 권고           │
│  긴급 알림           │
└──────────────────────┘
```

- 항상 고정 표시 (탭 바뀌어도 유지)
- 납기일 대비 생산시간 실시간 표시
- 생산속도 로직 확정 후 계산값 연동 예정

## 회사별 적용 방법

3개 회사 모두 동일한 컴포넌트 사용.
회사 구분은 props 또는 config로 처리.

| 회사 | 품목 데이터 | 단위 |
|------|------------|------|
| 옷감사 | 면/폴리에스터/린넨/울/혼방 × 컬러 | 야드 |
| 케어라벨사 | 라벨코드별 | 장 |
| 지퍼단추사 | 원목단추/플라스틱단추/금속단추/지퍼 | 개 |
